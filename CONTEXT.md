# Code Club Cambridge

The site curates the club's sessions and learning resources for young coders. Trusted volunteers maintain that public content.

## Language

**Mentor**:
An approved volunteer whose verified Google account may manage club content.
_Avoid_: Admin, user, editor

**Project**:
A published learning activity recommended by the club.
_Avoid_: Submission, resource, exercise

**Project collection**:
A named grouping used to present projects together, such as the main catalogue or the micro:bit topic.
_Avoid_: Category, list

**Interest**:
Something a coder wants to make or explore, such as a game, story, website, or 3D print.
_Avoid_: Language, level

**Coding tool**:
The language, editor, or hardware environment used to complete a project, such as Scratch, Python, HTML, or Unity.
_Avoid_: Interest, topic

**Challenge**:
An indication of how demanding a project is, expressed as Level 1, Level 2, or Level 3.
_Avoid_: Intro, age range

**Topic guide**:
A curated introduction and project collection for an optional focus session.
_Avoid_: Project, coding tool

**Club session**:
A scheduled Code Club meeting that may be open, cancelled, or linked to booking.
_Avoid_: Event, date
